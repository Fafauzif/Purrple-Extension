Connect Google Calendar

Purrple can show upcoming events on your primary Google calendar and create events after you review them. The extension and its core tools work without this connection.

  1. Extract Purrple_Complete_Source.zip. Install Python 3.10 or newer if needed.
  2. In your own Google Cloud project, enable Google Calendar API. In Google Auth Platform, configure the app and add your Google account as a test user if the app audience is External and the status is Testing.
  3. Under Clients, create an OAuth client of type Desktop app. Download its JSON. Keep it outside the source folder and keep it private.
  4. Open a terminal in the extracted source folder. On Windows run py tools/calendar/setup_calendar.py install "C:\path\to\downloaded-client.json". On regular desktop Linux or macOS run the same command using python3 and your actual JSON path.
  5. Load Purrple_Firefox_Extension.zip through about:debugging → This Firefox → Load Temporary Add-on. Open Purrple Settings and choose Allow Calendar data if shown, then Connect Google Calendar. Allow Firefox to use the local helper and finish Google consent in your default browser.

External Google apps in Testing may need reconnection after seven days. If your account is managed, its policy may block Calendar access. To remove the connection, use Disconnect in Purrple Settings, then run py tools/calendar/setup_calendar.py uninstall or the equivalent with python3.
