Install Purrple 3.2

Purrple keeps your plans, focus sessions, and companion progress in this browser profile. Your workday and games work offline.

Firefox

  1. Open about:debugging#/runtime/this-firefox and choose Load Temporary Add-on….
  2. Select Purrple_Firefox_Extension.zip, or select manifest.json inside the extracted archive.
  3. Pin Purrple from the Extensions menu and refresh website tabs you already have open.

Firefox removes a temporary add-on on restart. To update a permanent installation, obtain the signed update through the existing Mozilla Add-ons entry. For a self-distributed update, select the signed .xpi using Install Add-on From File… under the gear menu in about:addons.

Brave or Chrome

  1. Extract Purrple_Chromium_Extension.zip to a permanent folder.
  2. Open brave://extensions or chrome://extensions and enable Developer mode.
  3. Choose Load unpacked and select the folder containing manifest.json. Keep that folder for future updates and use Reload after replacing the files.

Make your first plan

Open Purrple from your toolbar to add a task in Today. Use Calendar to set aside time, or start a Focus session on a task. Click Purrple on a supported webpage for the planner, conversation, games, and gifts.

Download a backup in Settings before an update or a browser move. Review the import preview before you replace a save.
