# Purrple 3.0

The toolbar opens directly to Today. On a supported webpage, click Purrple to open your tasks, start a focus session, talk, play, or give her something.

- The compact planner supports adding, editing, completing and starting focus from tasks. Calendar has a compact Agenda for scheduling beside the page.
- Games open in place. Paw Pairs has 3 × 4, 4 × 4, and 4 × 6 boards. Cozy Clues has themed packs with hints. Pocket Pong and Three Paws join Lantern Paths as games to discover. You can leave an unfinished round and return to it later.
- Purrple responds when you give a gift. Her Bond progress shows how close you are to the next level.
- Turn on **Say hello on familiar sites** in Settings for an occasional greeting on supported video, music, writing, reading, or code sites. Purrple uses the hostname to choose a greeting and keeps it local.
- The interface uses a more compact planner and a study-room palette. Purrple’s existing artwork and the fitted wardrobe still use the shared renderer.

Export a backup from Settings before installing an update. Keep an unpacked Brave or Chrome installation in the same directory. For a permanent Firefox update, use Mozilla’s signed XPI for the existing extension ID.
