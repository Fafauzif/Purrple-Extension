# Purrple 3.2

Purrple now brings her last position and resting pose to the next supported webpage. Returning to an active tab reuses the warmed artwork when it is still available. While you drag or throw her, a new page receives a safe grounded position.

Talk replies stay in front of the planner and continue to work while it is pinned. The character’s default size is shared across the full app and websites. Compact and very narrow surfaces fit the sprite to the space available. In Room, Arrange room has grouped controls, position readouts, and sliders that work with the keyboard.

## Workday changes

- Open Commands with Ctrl+K or Cmd+K, or use the dashboard Commands control and the toolbar wordmark.
- Task checkboxes respond during a save and roll back with feedback if the write fails. Calendar and Room actions offer Undo.
- On browsers that support view transitions, dashboard and toolbar navigation share a short appearance transition when there is a visible character on both sides. Reduced motion uses immediate navigation.
- Paw Pairs previews the selected board size before Begin. Games still restore a saved round.
- The planner shows placeholder rows for a slower first read. These stay inside the usual Today layout.
